# 1.0.0

- Choose a percentage for each of SAIN's eight personalities in F12.
- Apply the mix to PMCs only, independently of level and equipment.
- Default mix: Normal 30%, Chad 10%, Wreckless 10%, Rat 20%, Snapping Turtle 10%, Coward 10%, Timmy 5%, GigaChad 5%.
- Display effective chances when values do not total 100.
- Keep each bot's selected personality across SAIN preset reloads while loading the new preset's behavior settings.
- Include an Enabled switch and optional assignment logging. Changes apply to new bots.

Built against SAIN 4.5.1 for SPT 4.1. Automated checks and a short solo raid test passed. The revised default mix needs longer raid testing; multiplayer has not been validated.
